# Digi Memoir prototype

Public, sample-only design review. Open index.html or the GitHub Pages site. Website, responsive mobile web, journal, sample capture, calendar, nominee form and screen gallery. No sign-in, real recording, uploads, invitations or backend. Changes reset on reload. No private user records.

All memories are owner-only in the proposed product; stars mark key moments. An approved nominee handover includes all data, including stars. Activation and verification rules still need review. This is design-only, not released Android/iOS apps.
